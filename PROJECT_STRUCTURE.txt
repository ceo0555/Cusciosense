MAIN ENTRY POINTS
=================

Frontend Development:
→ frontend/src/app/page.tsx              Landing page
→ frontend/src/app/dashboard/page.tsx    Dashboard
→ frontend/src/components/layout/        Layout components
→ frontend/src/lib/api/client.ts         API client

Backend Development:
→ backend/src/main.ts                    Application entry
→ backend/src/app.module.ts              Root module
→ backend/src/modules/auth/              Auth module
→ backend/src/modules/user/              User module


QUICK COMMANDS
==============

# Backend
cd backend
npm install          # Install dependencies
npm run start:dev    # Start development server
npm run build        # Build for production
npm run start:prod   # Start production server

# Frontend
cd frontend
npm install          # Install dependencies
npm run dev          # Start development server
npm run build        # Build for production
npm run start        # Start production server

# Database
createdb schoolos                        # Create database
cd backend && npm run migration:run      # Run migrations
